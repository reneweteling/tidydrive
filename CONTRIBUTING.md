# Contributing to TidyDrive

TidyDrive is source-available under the [PolyForm Noncommercial License 1.0.0](LICENSE.md). You are welcome to read the code, build it for yourself, and use it for any noncommercial purpose. Selling it, bundling it into a product, or using it inside a business needs a separate license.

## Pull requests are not accepted

This is a one-person project and I keep the copyright on every line. A pull request is closed automatically with a note pointing here. Nothing personal.

## What is welcome

- Bug reports: [open an issue](https://github.com/reneweteling/tidydrive/issues/new?template=bug.yml). Paste the version from Settings, About. If TidyDrive offered something for removal that it should not have, name the tool and the folder.
- A tool, cache or ecosystem TidyDrive does not know yet: [open an issue](https://github.com/reneweteling/tidydrive/issues/new?template=feature.yml) with the path it uses and the command that cleans it.
- Questions: an issue is fine too.

## Building from source

See the README. `./scripts/build.sh` produces an ad-hoc signed `build/TidyDrive.app` for your own machine.
